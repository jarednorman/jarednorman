# Bro. Say it simpler.

Your last message was too dense, jargon-heavy, and/or formal. Re-explain your most recent message in a simple, straightforward way. Write like you're speaking to an intelligent friend.

## Rules

1. Avoid unnecessary technical language and jargon.
2. Don't add new information. Re-explain only what was just said.
3. Don't simplify the facts, only the way you're communicating them.
4. Flatten the structure. Drop headers, tables, and lists. Just write in plain paragraphs.
5. Be direct. Get to the point with minimal ceremony and filler.
